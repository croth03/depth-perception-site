# Depth Perception — presentation website

A static, multi-page design presentation for the original game concept **Depth Perception**.

## Open locally

Open `index.html` directly, or serve this folder with any static HTTP server. All project pages, scripts, and images use relative paths, so the site is compatible with GitHub Pages and itch.io HTML5 hosting.

## Pages

- `index.html` — home / pitch
- `01-game.html` — game overview
- `02-case-study.html` — Mutant Mudds and Phase Shift Foundry case study
- `03-ai-discussion.html` — critical AI design discussion
- `04-concept.html` — three-stage concept
- `05-journey.html` — flowchart and storyboard
- `06-style-sound.html` — visual and audio direction
- `07-build-plan.html` — two-week build and test plan
